# Sistema-de-gesti-n-para-el-Hospital-Salud-Integral---5to-E
Sistema de gestión hospitalaria para administrar pacientes, citas, médicos, consultas, servicios y medicamentos. Desarrollado con C# y .NET para aplicaciones de escritorio (frontend y backend), utilizando MySQL Server como base de datos, con gestión de usuarios, permisos y seguridad.
